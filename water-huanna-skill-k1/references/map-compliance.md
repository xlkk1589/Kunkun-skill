# 地图类图表合规规则

地图 Style ID 89—93 及其他含地理边界的图形必须执行本规则。

1. 记录边界数据来源、版本、坐标参考系、投影、裁切范围和底图来源。
2. 中国地图必须完整、准确表示国界，中国台湾、南海诸岛等要素需符合国家标准。
3. 默认在线底图采用腾讯地图；可选高德、百度或天地图。禁止直接使用境外在线瓦片源。
4. 不在前端写入有效地图 API Key。需要自有 Key 时使用明确占位符，并提醒配置域名白名单或后端代理。
5. 涉及公开发布时核验审图号及地图审核要求。缺少合法边界或审核条件时停止生成公开发布版。
6. 不展示军事禁区、涉密实体或未公开敏感坐标。个人位置数据仅限本地私有处理。
7. 在线地图使用 GCJ-02；科研空间分析可以使用明确 EPSG 的投影坐标，但显示层和分析层之间必须记录转换过程。

地图缺项报告至少包含：缺少内容、必要性、当前影响、可接受补充材料。
