# 数据契约与复现闸门

## 1. 通用输入

优先使用整洁长表。每行表示一个观察单元，每列表示变量。保留原始重复观测、分组、配对或受试者 ID、时间、缺失状态和量纲。

支持直接检查的格式：CSV、TSV、JSON、GeoJSON、XLSX。Newick、Shapefile、GeoPackage、栅格和空间转录组矩阵作为专用结构输入，由对应 Style ID 的实现读取。

## 2. 字段角色

| 角色 | 含义 | 常见字段 |
|---|---|---|
| `sample` | 样本或观察单元 | sample_id、样本编号 |
| `subject` | 配对或重复测量对象 | subject_id、patient_id |
| `group` | 处理、类型或组别 | treatment、condition |
| `value` | 连续响应值 | value、abundance、response |
| `time` | 可排序时间 | date、year、time |
| `effect` | 效应量 | log2FC、beta、estimate |
| `lower`、`upper` | 区间上下限 | ci_low、ci_high |
| `source`、`target`、`weight` | 网络或流图边表 | from、to、strength |
| `longitude`、`latitude`、`crs` | 空间位置与坐标系 | lon、lat、EPSG |

字段名无法自动识别时，使用 `--map role=column` 明确映射。

## 3. 硬约束

出现以下情形时停止渲染并输出缺项报告：

1. 推断图仅有均值，缺少原始重复观测或已验证的统计结果。
2. 配对图缺少 `subject`。
3. 重复测量图缺少 `subject` 或 `time`。
4. 森林图缺少 `estimate`、`lower` 或 `upper`。
5. 网络、桑基或和弦图缺少 `source`、`target` 或 `weight`。
6. 系统发育图缺少 Newick 树或叶节点注释。
7. 地图缺少坐标系、边界来源或合规核验信息。
8. L2 缺少字体、配色、主题、标注规则或画布规格。
9. L3 缺少原代码、原数据、包版本、字体文件、随机种子或输出设备。

## 4. 推荐顺序

推荐流程固定为：数据画像、研究问题识别、候选召回、硬约束过滤、多目标评分、结果解释。

评分侧重科学适配和数据完备性。视觉新颖度不能抵消统计设计缺陷。首选图形需给出推荐理由，至少保留两个备选，并解释未入选图形的字段缺口或误读风险。

## 5. 复现等级

| 等级 | 验收要求 |
|---|---|
| L1 科学等价 | 变量映射、数据处理、统计结果和图形语义一致 |
| L2 视觉高保真 | 增加图层、布局、配色、字体、比例、标签和导出规格一致 |
| L3 像素级 | 增加原代码、原数据、依赖版本、字体、随机种子和图形设备一致 |

不得将近似图标记为“完美复现”。无法达到目标等级时，列明缺项及其影响。
